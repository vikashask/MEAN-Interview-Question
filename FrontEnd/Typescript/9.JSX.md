# TypeScript & JSX

## What is JSX?
JSX is an **embeddable XML-like syntax** meant to be transformed into plain JavaScript function calls (e.g., `React.createElement(...)`). TypeScript understands JSX natively when files use the **`.tsx`** extension.

```tsx
const element = <h1 className="title">Hello, TypeScript!</h1>;
// Transforms roughly to:
// React.createElement('h1', { className: 'title' }, 'Hello, TypeScript!')
```

## The `jsx` compiler option (tsconfig.json)
| Mode | Output | When to use |
|---|---|---|
| `preserve` | Keeps JSX as-is (`.jsx` output) | Another tool (Babel) will transform it |
| `react` | `React.createElement(...)` calls | Classic React (pre-17) without the new JSX transform |
| `react-jsx` | Auto-imports `jsx()` from `react/jsx-runtime` | **Modern React 17+** (no need to `import React` in every file) |
| `react-native` | Preserves JSX, `.js` output | React Native projects |

```json
{
  "compilerOptions": {
    "jsx": "react-jsx"
  }
}
```

## Typing JSX elements
- `JSX.Element` — the return type of a component/expression that renders JSX.
- `JSX.IntrinsicElements` — defines which lowercase tags (`div`, `span`, ...) are valid and what props they accept; this is how TS knows `<div onClick={...}>` is valid but `<div onClic={...}>` is not.

```tsx
function Title(): JSX.Element {
    return <h1>Hello</h1>;
}
```

## Typing custom components & props
```tsx
interface ButtonProps {
    label: string;
    onClick: (e: React.MouseEvent<HTMLButtonElement>) => void;
}

const Button = ({ label, onClick }: ButtonProps) => (
    <button onClick={onClick}>{label}</button>
);
```

## Generic components in JSX
Generic arrow function components need a trailing comma (`<T,>`) in `.tsx` files so the parser doesn't confuse `<T>` with a JSX tag:

```tsx
const List = <T,>({ items }: { items: T[] }) => (
    <ul>{items.map((i, idx) => <li key={idx}>{String(i)}</li>)}</ul>
);
```

## Interview quick hits
- **Q: What file extension is required for JSX + TypeScript?** `.tsx` (not `.ts`).
- **Q: Difference between `jsx: react` and `jsx: react-jsx`?** `react-jsx` uses the new automatic runtime — no need to import `React` just to use JSX.
- **Q: Why does `<T,>` need a trailing comma in generic components inside `.tsx`?** To disambiguate a generic type parameter from the start of a JSX tag.
